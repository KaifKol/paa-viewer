View, inspect, resize, and convert PAA textures for Arma 3, DayZ, and other Bohemia Interactive games.

ABOUT THIS SOFTWARE

PAA Viewer is a desktop application for PAA and PAC textures. It opens textures without starting the game, displays their channels, mipmaps, pixels, and metadata, and converts them to or from common image formats.

[h2]Install from Steam Workshop[/h2]

[b]Steam downloads PAA Viewer as a mod package. It does not install the desktop application automatically.[/b]

[list=1]
[*]Download or subscribe to the PAA Viewer mod in Steam Workshop.
[*]Wait until Steam finishes downloading the mod.
[*]Open the downloaded mod and unpack it.
[*]Open the [b]paa-viewer[/b] folder inside the unpacked mod.
[*]Take the Windows or Linux package from that folder.
[/list]

The unpacked mod contains two folders:

[list]
[*][b]paa-viewer[/b]: the Windows ZIP and Linux AppImage.
[*][b]addons[/b]: the Workshop PBO. It is not used to start the viewer.
[/list]

[h2]Steam installation on Windows[/h2]

[list=1]
[*]Open the [b]paa-viewer[/b] folder from the unpacked mod.
[*]Copy [b]paa-viewer-windows-x64.zip[/b] to a permanent location.
[*]Extract the ZIP archive.
[*]Open the extracted folder.
[*]Run [b]paa-viewer.exe[/b].
[/list]

Do not run the executable directly from the ZIP archive. Move the application before enabling file associations because Windows stores its current path.

[h2]Steam installation on Linux[/h2]

[list=1]
[*]Open the [b]paa-viewer[/b] folder from the unpacked mod.
[*]Copy [b]PAA_Viewer-x86_64.AppImage[/b] to a permanent location.
[*]Make the file executable with [b]chmod +x PAA_Viewer-x86_64.AppImage[/b].
[*]Run it with [b]./PAA_Viewer-x86_64.AppImage[/b].
[/list]

[b]Workshop updates:[/b] Steam updates the downloaded mod, not the standalone copy. After an update, copy and extract the new files from the mod again.

[h2]What PAA Viewer can do[/h2]

[b]Open and inspect textures[/b]

[list]
[*]Open PAA, PAC, PNG, JPEG, TGA, BMP, and WebP files.
[*]View RGBA, RGB, alpha, red, green, or blue channels.
[*]Inspect pixel coordinates, RGBA values, hexadecimal color, and a color sample.
[*]Inspect the PAA format, dimensions, tags, alpha flag, data size, and stored colors.
[*]Open individual mipmap levels and inspect their dimensions and compressed size.
[*]Zoom toward the cursor, pan by dragging, use 1:1 view, or fit the image to the window.
[*]Switch between nearest-neighbor and linear display filtering.
[/list]

[b]Convert and export[/b]

[list]
[*]Convert PAA and PAC textures to PNG, JPEG, TGA, BMP, or WebP.
[*]Convert common image formats to PAA or PAC.
[*]Export PAA as DXT1, DXT3, DXT5, ARGB8888, ARGB1555, ARGB4444, or GRAYA.
[*]Generate PAA mipmaps automatically.
[*]Convert one file in the desktop application or process a directory from the command line.
[/list]

[b]Resize textures[/b]

[list]
[*]Halve or double the current dimensions.
[*]Scale by a custom factor.
[*]Round dimensions to the nearest, next, or previous power of two.
[*]Stretch to an exact width and height.
[*]Fit inside a target size while preserving aspect ratio and pad the remaining area.
[*]Use Lanczos, bilinear, or nearest-neighbor resampling.
[*]Use 256, 512, 1024, and 2048 pixel presets.
[/list]

[b]Settings and integration[/b]

[list]
[*]Choose whether files launched from Explorer, Linux file managers, or the command line reuse the running viewer or open in a separate window.
[*]Manage file associations, thumbnail previews, and context menus from the Settings window.
[/list]

[h2]Basic workflow[/h2]
[list=1]
[*]Start PAA Viewer.
[*]Select [b]Open File[/b] or drag a texture into the window.
[*]Inspect its channels, pixels, metadata, and mipmaps.
[*]Resize it if required.
[*]Select the PAA format and mipmap option under [b]PAA Export Settings[/b].
[*]Select [b]Export As[/b] and choose the output path.
[/list]

Files launched from Explorer, file managers, or the command line can either reuse the current viewer window or open in a separate native window, configurable under [b]Settings[/b]. In-app [b]Open File[/b] and drag-and-drop always replace the texture in the current window.
[h2]Command line[/h2]

The command line can inspect metadata, convert individual files, and process entire directories.

[list]
[*]Run [b]paa-viewer --help[/b] to see the available commands.
[*]Run [b]paa-viewer COMMAND --help[/b] for options accepted by a command.
[*]On Windows, use [b].\paa-viewer.exe[/b] from the extracted application folder.
[/list]

Commands, resize modes, and complete examples are documented here:

[url=https://github.com/KaifKol/paa-viewer#command-line]Command-line documentation on GitHub[/url]

[h2]File associations, right-click actions, and thumbnail previews[/h2]

Thumbnail previews, file associations, and context menus are enabled by [b]System Integration[/b]. Note that file-manager thumbnail caches may need to be refreshed or the file manager reopened to display newly generated previews. Enable integration only after moving the application to its final location.

[b]Windows[/b]

[list]
[*]Generate thumbnail previews for PAA and PAC files in Windows Explorer.
[*]Open PAA and PAC files by double-clicking them.
[*]Convert PAA and PAC files to PNG from Explorer.
[*]Convert PNG, JPEG, TGA, BMP, and WebP images to DXT5 PAA.
[*]Convert PNG images to DXT1 PAA.
[/list]

[b]Linux[/b]

[list]
[*]Generate thumbnail previews for PAA and PAC files in FreeDesktop file managers.
[*]Register the [b]image/x-paa[/b] MIME type.
[*]Set PAA Viewer as the default application for PAA and PAC files.
[*]Install conversion actions for Dolphin, Nautilus, and Nemo.
[/list]

Use [b]Settings[/b] -> [b]System Integration[/b] in the desktop application. Command-line alternatives are listed in the GitHub documentation above.
[h2]Important behavior[/h2]

[list]
[*]Channel selection, zoom, and display filtering only affect the preview.
[*]Resizing changes the working copy. The source file is not changed until it is exported to that path.
[*]An explicit output path may replace an existing file.
[*]DXT compression is lossy. Keep the original image when you may need to edit it again.
[*]PAA Viewer works locally and does not upload textures.
[*]Arma 3, DayZ, and Bohemia development tools do not need to be running.
[/list]
